# Week 7 – SQL Joins

Practice PostgreSQL relationships, `JOIN`s, self-joins, and subqueries using the Country Club database.

## Contents

* `compose.yml` – PostgreSQL and pgAdmin setup
* `relationships.sql` – Table relationships and examples
* `joins.sql` – Joins and subquery exercises

## Run

```bash
docker compose up -d
```

Open pgAdmin at `http://localhost:8080` and run the SQL files in the Query Tool.

**Branch:** `week7/sqljoins`
