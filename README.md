# TypeScript Callbacks, Promises & Fetch

This project practices TypeScript function types, callbacks, asynchronous callbacks, Promises, and API requests using `fetch()`.

## Skills Covered

* **Callbacks & Function Types**

  * Order confirmation with callbacks
  * Named callback types
  * Callback functions that return values
  * Comparing numbers with callbacks

* **Asynchronous Callbacks**

  * Countdown timers using `setTimeout`
  * Delayed greetings
  * Understanding execution order

* **Callbacks That Return Values**

  * Celsius to Fahrenheit/Kelvin conversion
  * Processing arrays with a custom reduce-style callback
  * Function/type naming collisions

* **Promises**

  * Creating and handling Promises
  * Resolving and rejecting Promises
  * Understanding execution order
  * Using `.then()` and `.catch()`

* **Promises with Fetch**

  * Fetching advice from the Advice Slip API
  * Checking `response.ok`
  * Typing API responses
  * Handling invalid requests with `.catch()`

* **Second API**

  * Fetching data from another public API
  * Creating a custom response type
  * Handling errors as `unknown`

## Technologies

* TypeScript
* JavaScript Promises
* Fetch API
* `setTimeout`
* Public REST APIs

## Running the Project

Install the required dependencies if needed, then run the TypeScript files using the project's configured TypeScript/Node setup.

The examples log their results directly to the console, including successful callbacks, Promise results, API responses, and handled errors.

## Purpose

The goal of this assignment is to understand how TypeScript types work with callbacks and asynchronous code, and how Promises and `fetch()` can be used safely with typed API responses and error handling.
