# Typescript-Exercises
Practice typescript


# Skill 1 - Union Types ( | means OR)

* **ID Card:** Created an `IDType` using a union type (`number | string`) and an arrow function `showID` to display the ID.
* **Fruit Basket:** Created a `Fruit` type that only accepts `"apple"`, `"banana"`, or `"orange"`, and used `eatFruit` to display the fruit eaten.
* **Pass or Fail:** Created a `Result` type using `true | false` and an arrow function `printResult` with an `if` statement to return `"Pass"` or `"Fail"`.
* **Concepts Practiced:** Type aliases, union types, arrow functions, return types, `if-else` statements, and `console.log()`.

# Skill 2: Interfaces & Type Aliases ( & means AND)
* **Book Interface:** Created a Book interface with title and pages, and an arrow function describeBook to describe the book.
* **Combining Interfaces:** Created Teacher and Employee interfaces and combined them using SchoolTeacher with the & operator.
* **Favorite Car:** Created a Car interface and an arrow function printCar to display the car brand and year.
* **Concepts Practiced:** Interfaces, type aliases, intersection types (&), arrow functions, return types, and console.log().

# Skill 3: Enums
* **Color Picker:** Created a Color enum with Red, Green, and Blue, and an arrow function showColor to display the selected color.
* **Pizza Order:** Created a PizzaSize enum with Small, Medium, and Large, and an arrow function orderPizza to display the selected pizza size.
* **Role-Based Access:** Created a Role enum with Admin, User, and Guest, and an arrow function printRole using a switch statement to display the appropriate access message.
Concepts Practiced: Enums, arrow functions, parameter types, return types, switch statements, template literals, and console.log().
