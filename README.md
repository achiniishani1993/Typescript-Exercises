# Async/Await Assignment

This assignment is about working with **Promises**, **async/await**, **try/catch**, and **fetch()** in JavaScript/TypeScript.

## Tasks

### Easy

* **Task 1:** Refactor a coin flip to use `async/await` and `try/catch`.
* **Task 2:** Refactor a Promise that resolves or rejects using `async/await`.
* **Task 3:** Use `async/await` with a delayed Promise.

### Medium

* **Task 4:** Fetch advice from an API using `async/await`.
* **Task 5:** Check `response.ok` and handle errors with `try/catch`.
* **Task 6:** Fetch two pieces of advice one after another using `await`.

### Optional

* **Task 7:** Flip a coin and fetch advice only if the result is a win.
* **Task 8:** Use `Promise.all()` to run two requests at the same time.
* **Task 9:** Create your own async function that fetches data from an API.

## Technologies

* TypeScript
* Promises
* Async/Await
* Try/Catch
* Fetch API
* Promise.all()

## Goal

The goal is to learn how to work with asynchronous JavaScript using `async/await` and handle errors correctly.
